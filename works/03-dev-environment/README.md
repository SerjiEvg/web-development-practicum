# Практическая работа 3 — Настройка среды веб-разработки

**Раздел практикума:** стр. 69–93.

## Что нужно сделать
1. Установить и настроить Visual Studio Code.
2. Создать `index.html` с первым HTML-кодом.
3. Установить расширение Live Server и открыть страницу через локальный сервер.
4. Создать/использовать GitHub-репозиторий и опубликовать первую страницу через GitHub Pages.
5. Установить и настроить `ngrok` для временного внешнего доступа к локальному серверу.
6. Познакомиться с Postman для отправки HTTP-запросов и работы с API.
7. Освоить Chrome DevTools: Elements, Console, Sources, Network, Performance, Memory, Application и Security.
8. Сохранить скриншоты ключевых этапов и оформить отчёт.

## Результат
Рабочее локальное веб-приложение, репозиторий GitHub, опубликованная страница и отчёт с подтверждением выполнения.
