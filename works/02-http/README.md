# Практическая работа 2 — Анализ протокола HTTP

**Раздел практикума:** стр. 37–56 и далее.

## Что нужно сделать
1. Открыть предоставленный файл трассировки HTTP в Wireshark.
2. Определить количество пакетов и общий объём трафика.
3. Определить количество HTTP Request и HTTP Response.
4. Применить фильтры `http`, `tcp`, а также фильтрацию трафика по TCP/UDP и порту 80.
5. Найти GET-запрос и разобрать его HTTP-заголовки.
6. Исследовать соответствующий HTTP-ответ и передаваемые данные.
7. Зафиксировать результаты скриншотами и пояснить наблюдаемое взаимодействие клиента и сервера.

## Результат
Отчёт по анализу трассировки с фильтрами, найденными запросами/ответами и выводами.
