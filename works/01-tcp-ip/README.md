# Практическая работа 1 — Диагностические утилиты TCP/IP

**Раздел практикума:** стр. 7–34.

## Что нужно сделать
1. Изучить справку по `ipconfig`, `ping`, `tracert`, `hostname`.
2. Определить имя рабочего хоста.
3. Исследовать конфигурацию TCP/IP с помощью `ipconfig` и оформить таблицу: IP-адрес, маска, шлюз, DHCP, DNS, физический адрес и др.
4. С помощью `netstat` получить сведения о текущих соединениях и статистике TCP/UDP/ICMP/IP.
5. Исследовать выбранный преподавателем сетевой ресурс.
6. Проверить доступность ресурса с помощью `ping`.
7. Исследовать маршрут до ресурса с помощью `tracert`.
8. Сформировать отчёт со скриншотами и загрузить его в каталог студента.

## Результат
Отчёт с командами, результатами их выполнения, скриншотами и краткими выводами.
