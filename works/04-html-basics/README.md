# Практическая работа 4 — Знакомство с базовыми тегами HTML

**Раздел практикума:** стр. 96–133.

## Что нужно сделать
Изучить структуру HTML-документа и создать страницу с базовыми элементами: заголовками, абзацами, ссылками, изображениями, списками, таблицами, формами и метаданными. Отдельно рассматриваются SVG и оформление страницы 404.

## Материалы
- `assets/signs/` — графические материалы из исходного архива практикума.

## Результат
HTML-страница с корректной структурой, подключёнными ресурсами, навигацией и демонстрацией основных HTML-элементов.
