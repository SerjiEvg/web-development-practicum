# Правила работы с репозиторием

1. Каждая практическая работа хранится в отдельном каталоге `works/NN-name/`.
2. Исходный код студенческих решений не смешивается с методическими материалами.
3. Файлы отчётов студентов следует хранить отдельно от эталонных материалов, если это требуется преподавателю.
4. Имена новых файлов желательно задавать латиницей или использовать понятные русские имена без пробелов.
5. Не коммитить пароли, токены, ключи API и персональные данные.
6. Для публикации через GitHub Pages точкой входа должен быть `index.html` в выбранной структуре публикации.
